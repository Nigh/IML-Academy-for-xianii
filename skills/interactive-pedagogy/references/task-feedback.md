# 现实任务的交互反馈

设计或审查交互时必读。本文负责操作与反馈规格，不另设开场场景选择体系；先确认任务及其数学对应，再填写规格卡。

## 六问规格卡（每个交互必填）

每个交互必须回答以下六问，并把预测与数学条件写进同一张规格卡：

| 问题               | 必须可落实的信息                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 学生要发现什么？   | 明确正在模拟的现实任务或具体数学对象、与本课概念的对应、要观察的关系或不变量及预测问题                                  |
| 能操作什么？       | 场景中可控制量对应哪些数学变量，固定什么；标明范围、单位、步长/精度、约束、默认值、复位与非法输入策略                   |
| 操作后观察什么？   | 变量改变后哪些任务结果变化、重点比较什么；同步展示图形、数值、中间量和文字；标明解析/采样/预计算及尺度变化              |
| 为什么有助理解？   | 哪个对照区分哪些解释；模型内的受控变量关系不能外推成现实因果结论                                                        |
| 错误认识如何反馈？ | 具体错误 → 对应观察或反例 → 修正理由 → 再试入口；区分输入无效与概念误解                                                 |
| 何时可以继续？     | 用哪些新参数/输入/约束检验刚形成的认识，能作出何种预测或解释，以及如何重试/主动查看解释；不擅自添加强制通关或持久化门禁 |

## 现实反馈的选择

优先让操作改变任务中的量，并显示可解释的任务结果；以下是候选方式，不是每课必做的控件清单：

| 操作与反馈                           | 必须看清的关系或边界                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| 改变电阻值，观察分压结果             | 输入电压及负载假设固定时，电阻比怎样影响输出；理想模型不代表实测。              |
| 改变位置测量的时间窗口，观察平均速度 | 同一段运动中窗口、位移与平均速度的关系；更短窗口可能放大测量噪声。              |
| 调整向量方向和长度，观察合成位移     | 各动作对应哪条向量、终点怎样改变；固定坐标与比例，保留抵消等退化结果。          |
| 修改传感器噪声，观察数据分布         | 固定真实量与基础随机样本时，噪声参数怎样影响读数；标明分布假设、seed 与样本数。 |
| 改变采样率，比较连续模型与离散采样   | 采样点为何可能掩盖信号变化；解释信号及采样含义，不能把插值曲线当实测真值。      |
| 调整约束，观察可行解和最优解         | 哪些解被排除、目标怎样变化；包括无可行解或最优解不唯一的适用情形。              |

不熟悉的术语须用足以开始操作的短说明解释。界面必须说明模拟对象、可控变量、变化结果、观察重点、概念意义与新条件检验；不把完整作者规格表塞给学生，也不把滑块、图或动画本身当作教学成果。
