# 本地实验规范

网站只提供教程与参考文件，不运行本地 ML 环境，不自动连接用户设备，也不需要 API Key。

## 每节教程必须包含

1. 目标与理论前置链接。
2. 支持的平台、Python/库版本、CPU/GPU/设备条件。
3. 独立环境的建立与安装命令。
4. 数据来源、许可证、结构，或合成生成脚本。
5. 仓库参考代码位置与站内下载。
6. 运行步骤、命令、seed 与配置。
7. 预期输出、合理波动范围与耗时/硬件条件。
8. 分析方法、基线、消融、排错和进一步实验。
9. 实际验证环境与执行记录；未执行的步骤明确标注。

## 文件与资源

默认 `labs/lessons/<ID>/README.md`、`.py`、小型配置和测试；只有必要时用 notebook。
小型参考源文件需在 lesson.ts localLab.files 中逐个列出，由构建复制到站内资源。
禁止越界路径和超过 1 MiB 的参考文件；数据集/权重从公开合法来源获取，不提交仓库。
公共实验工具由维护者放 labs/shared；课程 Agent 不直接改共享环境。

无真实设备时使用明确标记的合成数据验证分析流程，不能把合成结果声称为设备实测。
GPU、MuJoCo 和硬件长实验不进入默认前端 CI。可运行轻量 CPU、配置、路径和语法检查。
