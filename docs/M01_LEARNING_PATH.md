## 跨链缺口的处理

- M01-009不依赖完整范数课程：课内明确L2就是欧氏长度，用配方替代必须会求导的跳跃。
- M01-011从行列开始定义矩阵，用逐项相乘求和定义行列内积，不默认先学M01-007。
- M01-013把一般奇异值计数公式列为补充，核心用已知伸缩矩阵说明数值阈值，不反向依赖SVD。
- M01-017正式依赖基与内积，课内给二维行列式定义，不用编号推断已经学过M01-015。
- M01-018正式补入秩的前置关系，以便从已经建立的方向数量理解非零奇异值计数。
- M01-001一般旋转矩阵、M01-003展平存储、M01-005最近距离属于补充层，不作为本课核心理解的门槛。

## 教学审阅方法

逐课对照正文、公式、实验与测验：正式前置是否真正教过；新定义是否有具体例子；参数变化能否预测；失败案例是否能说明原因。结构校验和自动浏览器检查不替代读者理解审阅。

本次新增内容与实验为原创；教学节奏参考 [Brilliant公开课程介绍](https://brilliant.org/math/) 的逐概念推进和交互验证，不复制题目、插图或付费内容。
