## 审查与重排

原课程普遍在 intuition/mathematics 先公布几何关系或算例，再在 experiment 要求预测同一结果。例如001先给出旋转90°的新分量；005先证明共线方向无法命中目标；009先配方求出最近点；013先解释微小非零方向的秩；017先解释90°旋转反例；019先算出截断误差；020先列出三点最优参数。多数课后的“先预测再操作”文字重复前文答案，实验后的场景列表又复述一次。002正式测验仅一道；007讨论余弦相似度却没有数值对照；020只能改变数据后观看自动拟合，不能亲手改变候选模型。

正文改为具体问题 → 前置提醒 → 有目标的实验与预测 → 解释观察 → 数学定义/推导 → 条件与反例 → 迁移 → 总结。每课只加一个可跳过的预测，保留正式测验，不设置通关。原有定义、符号、单位、假设、解析推导和至少两个误区保留；删去重复的答案型场景清单。迁移题改变表示、约束或任务，并要求说明理由。

每张卡的六项交互职责：

1. **认识与预测**：`exploration.ts` 的 prompt/options 对应表中问题，误选项来自本课具体误区。预测面对的是固定题目，不以自由探索后的任意参数重新定义答案。
2. **操作**：原 experiment.ts 与各课面板拥有参数、范围、单位和非法值校验。保留全部预设、键盘输入及重置；021的无效形状停算并显示原因。020新增候选截距/斜率范围±8、步长0.05，非法数不传播，复位均恢复1。
3. **观察**：复用 VectorDiagram、Plot2D、MatrixView 及018/012的原有SVG。所有读数由相同数学状态派生；模型明确标注解析计算。020的候选实线、解析最优虚线和观测圆点有非颜色区分，逐点表格跟随候选而非最优线。
4. **对照理由**：表中任务刻意控制变量，比较表示与对象、方向与尺度、独立与冗余、精确秩与数值阈值、存在性与唯一性、残差与范数。实验不代替一般证明；推导仍在数学部分。
5. **失败反馈**：选错后先指出应观察的对照，不自动展开答案。两级提示依次指出观察位置和推理步骤；完整解释需主动点击。选择变化清除评分，参数变化使旧反馈失效，复位清除选择、提示和解释；无效输入错误仍由原输入组件处理。
6. **继续条件**：预测与正式测验均不拦截阅读；可以直接探索。能说明受控变量、不变量和反例，并回答迁移题才是预期理解证据，点击次数不算掌握。
