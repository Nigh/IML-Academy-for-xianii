# 数学符号与数值约定

- 标量用斜体 x；向量用粗体小写，矩阵用大写；正文明确维度。
- 随机变量 X，观测值 x；样本索引 i，时间 t，批次轴 B，通道 C。
- 训练平均损失写经验风险，目标数据分布上的期望写期望风险；验证指标另行命名。
- 公式首次出现逐项解释，注明单位、形状、范围与假设。无量纲也须说明。
- log 默认自然对数；若用 bit 或 log10 明确标注底数。近似写约等于并说明误差来源。
- 梯度默认列向量；Jacobian 的行是输出、列是输入。矩阵乘法与逐元素运算不得混用。
- 卷积课明确数学卷积与框架互相关约定。时序相关明确 lag 符号。
- 向量距离需先检查量纲。位置/位移、旋转/向量、路程/位移不可混淆。
- 均值、方差说明总体或样本及分母。置信区间不解释为已实现区间的参数概率。
- 平方损失的 1/2、1/n 与正则项系数必须前后一致。
- 非有限输入、零分母、常数特征、奇异矩阵和不合法概率需明确错误或边界策略。
- 浮点断言说明绝对/相对容差，零附近优先绝对误差；不要声称跨硬件逐位复现。
