## M01-002 代表课

原交互：调整四个抽象分量和数乘系数，切换首尾相接/平行四边形，仅由向量图反馈结果。

实现：学生设置移动平台的两段东西/南北位移，依次执行第一段和第二段；观察平台中途位置、终点、实线/虚线路线。指令修改立即回起点，必须重新执行；完整复位同时恢复默认计划。倍率作用于第一段全部分量，负值表示反向。

同一 `a=ka₀`、`b`、`sum=a+b` 驱动平台、向量图与合位移/路程读数。对象只接收这些纯向量结果，不维护第二套模拟。分步状态只决定当前执行到哪个已算出的端点。地图横纵等比例并按计划取景，明确标尺/视域变化，跨场景按米数比较。

### 教学路径与准入

已学：物理位移、坐标分量、长度。新增：逐分量相加、首尾相接、正负数乘。后续：线性组合、内积。

A 建立任务：平台执行两段移动后，怎样记录最终位移与走过的路？B/C：先预测反向走回起点时这两种量是否相同，再执行路线。D：用分量记账引出加法与数乘公式。E：对照默认转向与完全抵消。F：推导一般二维列向量关系，讨论同向等号条件与单位/坐标系迁移。原有推导、三角不等式、两个误区及三道测验保留。

七项开场准入均通过：日常移动可理解；任务是比较终点和路径；已知两段位移、固定世界轴；可预测返回起点；加法精确表达终点；移动平台比纯箭头更直接；模型明确忽略障碍、加速及转向时间，不引入机器人工程前提。

六问规格：

| 问题       | 实现与证据                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------ |
| 发现什么   | 走过非零路程仍能回起点，位移不能用长度相加代替；先做 PredictionLab 预测                    |
| 操作什么   | B/C 简化平台与联动向量；四个位移输入 −5–5 m、倍率 −3–3、两次执行和重试；共享输入拒绝非法值 |
| 看见什么   | 起点→第一端点→最终端点，合位移和路程；解析计算，没有随机实验或实测宣称                     |
| 为何有用   | 将抵消从箭头规则变成“实际走了但回到原处”的任务结果；数学图继续解释一般运算                 |
| 错误反馈   | 路程=位移误解由抵消场景区分；负倍率误解由全部分量翻转区分；按需提示与主动看推理            |
| 新条件检验 | 改倍率、切换抵消、重新执行；单位/坐标迁移题要求解释何时可相加，不加完成门槛                |

九项对象准入均通过：对象为移动平台；动作是有单位的位移指令；端点与路线可见；先预测后验证；直接揭示加法；平台优于空白坐标；向量图用于推广；不加障碍规划、动力学或动画控件。

保留数学图的理由：本课还需理解一般向量的首尾相接、平行四边形及交换律；平台负责具体任务，向量图负责脱离路线执行顺序的数学表达，不能仅靠平台移动证明一般结论。

### 数学与交互证据

现有纯函数测试覆盖解析和 `(2,1)+(-1,2)=(1,3)`、完全抵消、零/负数乘、交换律、小数容差、非有限输入和溢出。组件测试新增两段实际执行、中途/最终位置、改参清理和抵消返回起点断言。浏览器回归新增键盘复位与指令改变后同一向量结果检查。
