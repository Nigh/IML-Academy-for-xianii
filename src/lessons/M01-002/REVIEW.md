## 设计依据

已学：M01-001 的位移、分量与长度。新增：连续位移逐分量相加、统一数乘、路径与合位移的区别。用途：根据目标安排绘图平台的两段指令。

采用工程场景 B 与交互方案 C：理想 XY 绘图平台联动向量图。笔头、两段移动、指定经过点与终点都有直接含义；二维视图已经能完整表达本课关系，无需 GRBL、切削知识或三维运行时。场景准入七项与操作对象九项均满足：任务可用日常语言说明，已知/目标/限制明确，已有分量知识足以尝试，操作会改变真实计算，路径偏差可观察，无额外领域前提。

叙事顺序：先提出沿目标路线绘图的任务；预测当前指令是否满足目标；尝试分方向计算并执行；用首尾相接和数乘解释；回到目标纠错；交换指令检验“同终点是否同路径”。既有数学定义、抵消/负数乘误区与单位迁移保留。

| 六问         | 本课落实                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| 发现什么     | 第一段末端与最终终点分别受什么指令影响；同终点不保证同路径                                            |
| 操作什么     | a、b 分量 −5 至 5 m，步长 0.1；k 为 −3 至 3 的无量纲数；非法输入不传播。任务选择只换目标，不填写解答  |
| 观察什么     | 平台位置、已走轨迹、目标 P/Q、两处距离、完整计划向量与路程。所有结果使用同一 a、b；解析插值每段 10 步 |
| 为什么有效   | 先到 P 后到 Q 的路径约束让仅求合向量的做法暴露不足；交换非平行指令保持终点却改变中间点                |
| 错误如何反馈 | 区分两处皆偏、只错终点、只错经过点与全部匹配；提示指出相对位移、k 同时作用两分量，支持重试及两层提示  |
| 何时继续     | 完成后交换指令并解释路径差异；第四道正式测验检验这一迁移。没有新增强制通关或持久化规则                |

## 数学与实现

- 三个目标：P=(2,1), Q=(3,3)；P=(2,−1), Q=(0,0)；P=(−4,−2), Q=(−5,0)，单位均为 m。
- 起点固定为零，要求 ka=P、b=Q−P；笔头每段线性插值，播放速度是演示步速，不是进给速度。
- 判定分别检查第一段末端和终点的欧氏距离；固定米尺度下使用 1e−8 m 绝对容差，只吸收浮点误差。图形读数舍入不参与判定。
- 复用 SimulationControls：单步、播放/暂停、速度、隐藏暂停、减少动态效果与清理；输入/任务改变会重建控制器并清除进度与反馈。完整复位同时恢复目标、输入及默认步速。
- 保留原三题 ID/版本/顺序，末尾追加路径迁移题，共四题；总结仍为四条，链接来自注册表。
- 使用 math-storytelling、interactive-pedagogy 及其场景/反馈资源；humanizer-zh 的规则内嵌在入口中，无外部 references 依赖；UI UX Pro Max 的 Svelte 生命周期查询与可访问性/响应式规则用于定向复核。中文润色保留量纲、模型限制、容差及条件强度。

这是二维理想位移模型，没有声称运行真实机床、GRBL、GPU 或物理动力学。实际检查、截图位置与检查结果记录在 PR 中；本设计记录不代替执行证据。
